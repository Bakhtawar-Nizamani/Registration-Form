# Course Registration Form

A simple and beginner-friendly Course Registration Form built using pure HTML.  
This project collects student, academic, course, and emergency contact information through a structured form layout.


# Features

- Student Information Section
- Academic Information Section
- Course Details Section
- Emergency Contact Section
- Declaration Section
- Radio Buttons
- Dropdown Menus
- Required Input Validation
- Organized using `fieldset` and `legend`

# Technologies Used

- HTML5


# Form Sections
👤 Student Information
   - Full Name
   - Father’s / Guardian’s Name
   - Date of Birth
   - Gender
   - CNIC / B-Form Number
   - Email Address
   - Phone Number
   - Home Address
🎓 Academic Information
  - School / College / University Name
  - Current Qualification
  - Grade / Semester
  - Previous Academic Result
📚 Course Details
  - Course Name
  - Course Duration
  - Preferred Batch Timing
  - Mode of Learning
🚨 Emergency Contact
  - Emergency Contact Name
  - Contact Number
